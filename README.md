# About

Hi! This is the source code for my personal homepage. Any feedback is welcome!

## Technical choices

 * Single page, 0 runtime dependency to load fast and keep maintenance minimal.
 * All code written by AI under my supervision.

## Building

1. Install dependencies: `npm ci`
2. Production build: `npm run build`
3. Interactive development: `npm run dev`

The output is docs/index.html (with CSS and JS embedded).
